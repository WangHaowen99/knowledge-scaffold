# 对象描述
客户下达的订单抬头。

# 对象别名
销货单

# 英文名称
demo_order_head

# 数据来源
demo_order_head
> 表名要在项目 schema 里核对，不存在时发布会被阻断。

# 查询边界
按 order_no 查询单张订单，按 created_at 查询区间。

# 对象属性清单
| 中文名称 | 英文名称 | 描述 | 主键 | 类型 | 属性别名 | 属性规则 |
|---|---|---|---|---|---|---|
| 订单号 | order_no | 订单的唯一编号 | 是 | 字符串 | 单号 | |
| 客户编码 | customer_code | 下单客户的编码 | 否 | 字符串 | | |
| 订单状态 | order_status | 订单当前状态 | 否 | 枚举 | | 取值：10=待审核 / 20=已审核 / 30=已发货 / 90=已关闭 |
| 订单金额 | order_amount | 订单总金额（元） | 否 | 小数 | | |
| 创建时间 | created_at | 订单的创建时间 | 否 | 日期 | | |
