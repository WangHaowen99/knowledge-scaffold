# 业务描述
审核员确认订单内容后把状态从待审核改为已审核。

# 与operation的关联
- 被operation调用 > 无
- 调用operation > 无

# 与object的关联
- 输入数据的对象：[[销售订单]]
- 输出数据的对象：[[销售订单]]
- 支撑数据的对象：无

# 与object的语义关联
| 业务对象 | 语义关联关系 |
|---------|--------|
| 销售订单 | 读取 order_status，把 10 改为 20 |

# 触发条件
状态为 10 的订单被提交审核。

# 输入
| 参数名称 | 描述 | 输入源 |
|--------|------|-------|
| order_no | 待审核的订单号 | 审核员选择 |

# 输出
| 参数名称 | 描述 |
|--------|----|
| order_status | 审核后的状态码 |

# 逻辑描述
校验订单状态为 10，通过后改为 20，否则拒绝并返回当前状态。
