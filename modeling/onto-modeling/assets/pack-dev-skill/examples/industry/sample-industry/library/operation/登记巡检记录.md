# 业务描述
巡检人完成一次巡检后登记结果。

# 与operation的关联
- 被operation调用 > 无
- 调用operation > 无

# 与object的关联
- 输入数据的对象：[[设备]]
- 输出数据的对象：[[巡检记录]]
- 支撑数据的对象：无

# 与object的语义关联
| 业务对象 | 语义关联关系 |
|---------|--------|
| 设备 | 校验设备存在，写回最近巡检时间 |
| 巡检记录 | 写入一条巡检记录 |

# 触发条件
巡检人提交巡检结果。

# 输入
| 参数名称 | 描述 | 输入源 |
|--------|------|-------|
| 设备编号 | 被巡检设备的编号 | 巡检人填写 |
| 巡检时间 | 巡检完成的时间 | 巡检人填写 |
| 判定结论 | 取值：正常 / 异常 | 巡检人填写 |

# 输出
| 参数名称 | 描述 |
|--------|----|
| 巡检编号 | 新写入的巡检记录编号 |

# 逻辑描述
校验设备存在后写入巡检记录，并更新设备的最近巡检时间；判定结论为异常时转入缺陷登记。
