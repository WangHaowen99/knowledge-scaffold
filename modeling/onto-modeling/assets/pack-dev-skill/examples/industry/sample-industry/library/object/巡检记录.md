# 对象描述
一次巡检的结果，记录被巡检设备、巡检时间和判定结论。

# 对象别名
巡检单、点检单

# 英文名称
inspection_record

# 数据来源
无
> 候选片段，表名按项目资料填写。

# 查询边界
按设备编号和巡检时间查询。

# 对象属性清单
| 中文名称 | 英文名称 | 描述 | 主键 | 类型 | 属性别名 | 属性规则 |
|---|---|---|---|---|---|---|
| 巡检编号 | record_no | 巡检记录的唯一编号 | 是 | 字符串 | 单号 | |
| 设备编号 | device_no | 被巡检设备的编号 | 否 | 字符串 | | |
| 巡检时间 | inspected_at | 巡检完成的时间 | 否 | 日期 | | |
| 判定结论 | verdict | 本次巡检的结论 | 否 | 枚举 | | 取值：正常 / 异常 |

# 关联对象
- 巡检记录 → 针对（device_no → device_no） → [[设备]]
