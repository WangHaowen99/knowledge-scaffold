# 对象描述
按门店等级和商品规定的陈列面数与陈列量上下限。补货时用陈列量上限截断补货量，避免货架放不下的商品堆进后仓。

# 对象别名
陈列标准, 排面标准, 满陈列量

# 英文名称
DisplayStandard

# 数据来源
无

# 查询边界
按门店等级与商品编码精确查询，或按门店等级批量查询；必要字段为门店等级、商品编码、陈列量上限；单次最多返回 5000 行，超出时提示按品类分批。无匹配时视为缺陈列标准，补货量不截断，并在补货结果中标注。

# 对象属性清单
| 中文名称 | 英文名称 | 描述 | 主键 | 类型 | 属性别名 | 属性规则 |
|--------|--------|-----|----|-----|--------|--------|
| 门店等级 | store_grade | 标准适用的门店等级 | 是 | 枚举 | 店级 | 取值：A / B / C |
| 商品编码 | sku_code | 标准约束的商品 | 是 | 字符串 | 货号 | 必填 |
| 陈列面数 | facing_count | 货架正面摆放的列数 | 否 | 整数 | 排面数 | 正整数 |
| 最小陈列量 | min_display_qty | 保证陈列饱满的最低数量 | 否 | 整数 | 陈列下限 | 非负整数；单位：件 |
| 陈列量上限 | max_display_qty | 货架可容纳的最大数量 | 否 | 整数 | 货架容量 | 正整数；单位：件；不小于最小陈列量 |
| 生效日期 | effective_date | 标准开始生效的日期 | 否 | 日期 | 无 | 必填 |
