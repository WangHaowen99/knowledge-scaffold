# 对象描述
直接面向顾客销售的经营单元，是补货单的收货方。门店等级决定适用的陈列量标准，区域编码决定适用的区域配额。

# 对象别名
分店, 网点, 营业网点

# 英文名称
Store

# 数据来源
无

# 查询边界
按门店编码精确查询，或按区域编码、门店等级、营业状态筛选；必要字段为门店编码、门店等级、营业状态；单次最多返回 1000 家门店，超出时提示按区域缩小范围。无匹配门店时返回空结果，不推断门店存在。

# 对象属性清单
| 中文名称 | 英文名称 | 描述 | 主键 | 类型 | 属性别名 | 属性规则 |
|--------|--------|-----|----|-----|--------|--------|
| 门店编码 | store_code | 门店的唯一标识 | 是 | 字符串 | 店号 | 必填；唯一 |
| 门店名称 | store_name | 门店的显示名称 | 否 | 字符串 | 店名 | 无 |
| 门店等级 | store_grade | 按销售规模划分的等级 | 否 | 枚举 | 店级, 门店分级 | 取值：A / B / C |
| 区域编码 | region_code | 门店所属的区域 | 否 | 字符串 | 片区编码 | 必填 |
| 营业状态 | business_status | 门店当前是否营业 | 否 | 枚举 | 无 | 取值：营业 / 停业 / 筹备 |
| 门店特殊需求 | special_demand | 门店提出的、与通用标准不同的要求说明 | 否 | 字符串 | 门店特需 | 与通用标准冲突时取严 |
