# 对象描述
配送中心在一个自然周内分配给某个区域、某个品类的补货数量上限，用于防止单家门店超量补货挤占同区域其他门店。

# 对象别名
区域额度, 区域限额, 片区配额

# 英文名称
RegionalQuota

# 数据来源
无

# 查询边界
按区域编码、品类编码、配额周期精确查询；必要字段为配额数量、已用数量；单次最多返回 1000 行。无匹配时视为该品类在该周期不受配额约束，并在结果中注明。

# 对象属性清单
| 中文名称 | 英文名称 | 描述 | 主键 | 类型 | 属性别名 | 属性规则 |
|--------|--------|-----|----|-----|--------|--------|
| 区域编码 | region_code | 配额适用的区域 | 是 | 字符串 | 片区编码 | 必填 |
| 品类编码 | category_code | 配额适用的品类 | 是 | 字符串 | 类目编码 | 必填 |
| 配额周期 | quota_period | 配额适用的自然周 | 是 | 字符串 | 配额周 | 格式：年份-W周序号 |
| 配额数量 | quota_qty | 周期内允许补货的总量 | 否 | 整数 | 额度 | 非负整数；单位：件 |
| 已用数量 | used_qty | 周期内已确认的补货量 | 否 | 整数 | 已用额度 | 非负整数；单位：件；派生：由 [[超量与审批提示]] 写入 |
| 审批阈值比例 | approval_ratio | 超出部分占配额的比例超过该值时升级审批 | 否 | 小数 | 无 | 取值 0-1；示例取 0.2 |
