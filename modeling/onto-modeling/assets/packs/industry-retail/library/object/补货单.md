# 对象描述
门店向配送中心申请补充商品的单据明细，一行对应一个门店的一个商品，记录建议补货数量、下单箱数和单据状态。

# 对象别名
订货单, 补货申请单

# 英文名称
RestockOrder

# 数据来源
无

# 查询边界
按补货单号查询，或按门店编码与补货日期筛选；必要字段为补货单号、门店编码、商品编码、建议补货数量；单次最多返回 5000 行，超出时提示按门店或日期分批，结果被截断时在回复中注明。无匹配时返回空结果，不推断补货已发生。
