# 对象描述
门店可售的最小管理单元，按商品编码区分。补货测算用到的箱规、保质期、到货周期等主数据都挂在商品上。

# 对象别名
单品, 货品, 品项

# 英文名称
Product

# 数据来源
无

# 查询边界
按商品编码精确查询，或按品类编码、商品状态筛选；必要字段为商品编码、箱规、商品状态；单次最多返回 5000 条，超出时提示按品类分批。无匹配商品时返回空结果。

# 对象属性清单
| 中文名称 | 英文名称 | 描述 | 主键 | 类型 | 属性别名 | 属性规则 |
|--------|--------|-----|----|-----|--------|--------|
| 商品编码 | sku_code | 商品的唯一标识 | 是 | 字符串 | 货号 | 必填；唯一 |
| 商品名称 | sku_name | 商品的显示名称 | 否 | 字符串 | 品名 | 无 |
| 品类编码 | category_code | 商品所属的品类 | 否 | 字符串 | 类目编码 | 必填 |
| 箱规 | case_pack_qty | 每箱包含的件数 | 否 | 整数 | 装箱数 | 正整数；单位：件/箱 |
| 保质期天数 | shelf_life_days | 商品的总保质期 | 否 | 整数 | 保质期 | 非负整数；单位：自然日；0 表示不管理效期 |
| 到货周期天数 | lead_time_days | 从下达补货单到商品到店可售的天数 | 否 | 整数 | 到货天数, 补货提前期 | 正整数；单位：自然日 |
| 商品状态 | sku_status | 商品是否允许补货 | 否 | 枚举 | 无 | 取值：正常 / 停购 / 淘汰 |

# 关联对象
