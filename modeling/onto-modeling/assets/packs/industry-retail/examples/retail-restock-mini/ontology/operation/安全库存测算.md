# 业务描述
按近 28 日有效销售日的日均销量、商品的到货周期天数和缓冲天数，测算某门店某商品的安全库存，并写回库存记录。

# 与operation的关联
- 被operation调用 > [[补货编制主流程]]
- 调用operation > 无
- 可单独调用 > 否

# 与object的关联
- 输入数据的对象：[[库存]]、[[商品]]
- 输出数据的对象：[[库存]]
- 支撑数据的对象：无

# 与object的语义关联
| 业务对象 | 语义关联关系 |
|---------|--------|
| 库存 | 读取近 28 日销量与有效销售天数，写回日均销量和安全库存 |
| 商品 | 提供到货周期天数 |

# 触发条件
[[补货编制主流程]] 逐商品调用。用户单独询问某门店某商品的安全库存时，按该商品编码执行 [[补货编制主流程]]，从其输出中取安全库存，这样门店营业状态、商品状态等前置检查不会被跳过。

# 输入
| 参数名称 | 描述 | 输入源 |
|--------|------|-------|
| 门店编码 | 待测算的门店 | 调用方传入，来自 [[补货编制主流程]] 的输入或用户提问 |
| 商品编码 | 待测算的商品 | 调用方传入，来自 [[补货编制主流程]] 遍历的 [[库存]].商品编码，或用户提问 |
| 补货日期 | 按该日的库存快照测算 | 调用方传入，来自 [[补货编制主流程]] 的输入，默认当天 |
| 缓冲天数 | 应对销量波动的额外天数 | 调用方传入，来自 [[补货编制主流程]] 的输入，默认 2 |

**查询边界**：按门店编码、商品编码、库存日期 == 补货日期 查询 [[库存]]，至多 1 行；按商品编码查询 [[商品]]，至多 1 行。无匹配库存记录时返回测算状态「无库存记录」，不按 0 销量测算；两次查询都按主键定位，不会截断。

# 输出
| 参数名称 | 描述 |
|--------|----|
| 日均销量 | 有效销售日的平均销量，单位：件/日 |
| 安全库存 | 单位：件，整数 |
| 测算状态 | 取值：正常 / 样本不足 / 无库存记录 / 缺到货周期 |

# 逻辑描述
1. 基于门店编码、商品编码、补货日期，查询 [[库存]]，读取近28日销售数量、近28日有效销售天数。
   - if 无匹配记录 then 测算状态 = "无库存记录"，结束
2. 基于商品编码，读取 [[商品]].到货周期天数
   - if not exists 到货周期天数 then 测算状态 = "缺到货周期"，结束
3. if 近28日有效销售天数 < 7 then 测算状态 = "样本不足"，不输出日均销量与安全库存，结束
4. 日均销量 = 近28日销售数量 / 近28日有效销售天数
5. 安全库存 = ceil(日均销量 × (到货周期天数 + 缓冲天数))
6. 将日均销量、安全库存写入该条 [[库存]] 记录，测算状态 = "正常"。

```
# 示例
# 输入：近28日销售数量 = 240，近28日有效销售天数 = 24，到货周期天数 = 2，缓冲天数 = 2
# 输出：日均销量 = 10，安全库存 = 40，测算状态 = "正常"
```
