# 对象描述
某一日门店持有的商品数量快照，包括现有库存、在途数量和近 28 日销售汇总。日均销量和安全库存由 [[安全库存测算]] 写入。

# 对象别名
存货, 库存量

# 英文名称
Inventory

# 数据来源
无
> 示例项目不附数据表；接入真实数据后改为对应的表名。

# 查询边界
必须同时给出门店编码和库存日期，可再按商品编码过滤；必要字段为门店编码、商品编码、库存日期、现有库存数量、在途数量；单店单日最多返回 5000 行，超出时提示按品类分批。无匹配记录时视为该商品没有库存记录，不按库存为 0 处理。

# 对象属性清单
| 中文名称 | 英文名称 | 描述 | 主键 | 类型 | 属性别名 | 属性规则 |
|--------|--------|-----|----|-----|--------|--------|
| 门店编码 | store_code | 库存所在的门店 | 是 | 字符串 | 店号 | 必填 |
| 商品编码 | sku_code | 库存对应的商品 | 是 | 字符串 | 货号 | 必填 |
| 库存日期 | stock_date | 快照日期 | 是 | 日期 | 快照日期 | 必填 |
| 现有库存数量 | on_hand_qty | 门店现存的商品数量 | 否 | 整数 | 现存量 | 单位：件；可能为负，测算时负数按 0 计 |
| 在途数量 | in_transit_qty | 已下发、尚未到店的数量 | 否 | 整数 | 在途量 | 非负整数；单位：件 |
| 计量单位 | unit | 本对象数量字段的单位 | 否 | 枚举 | 单位 | 取值：件 |
| 近28日销售数量 | sales_qty_28d | 近 28 天有效销售日的销量合计 | 否 | 整数 | 近四周销量 | 非负整数；单位：件；已剔除缺货日与促销日 |
| 近28日有效销售天数 | valid_days_28d | 近 28 天中营业、日初可用库存大于 0 且非促销的天数 | 否 | 整数 | 有效销售日数 | 取值 0-28 |
| 日均销量 | avg_daily_sales | 有效销售日的平均销量 | 否 | 小数 | 日均销售量 | 单位：件/日；派生：由 [[安全库存测算]] 写入；公式 = sales_qty_28d / valid_days_28d |
| 安全库存 | safety_stock | 覆盖到货周期和缓冲天数的最低库存 | 否 | 整数 | 安全存量 | 单位：件；派生：由 [[安全库存测算]] 写入；公式 = ceil(avg_daily_sales * (lead_time_days + buffer_days)) |

# 关联对象
- 当前对象 → 存放于（store_code → store_code） → [[门店]]
- 当前对象 → 对应（sku_code → sku_code） → [[商品]]
