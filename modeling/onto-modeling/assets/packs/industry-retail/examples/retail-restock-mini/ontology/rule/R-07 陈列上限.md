# 规则描述
补货后门店库存不超过商品的陈列量上限，避免货架放不下的商品堆进后仓，增加损耗和盘点差异。

# 规则类型
校验约束

# 适用对象
- [[商品]]：陈列量上限，箱规
- [[库存]]：现有库存数量，在途数量
- [[补货单]]：建议补货数量，下单箱数

# 触发条件
[[补货编制主流程]] 算出下单箱数之后、写入补货单之前。

# 约束表达
本次补货后的库存，即可用库存加上建议补货数量，不得超过商品的陈列量上限；现有库存为负时按 0 计。
`max(库存.现有库存数量, 0) + 库存.在途数量 + 补货单.建议补货数量 <= 商品.陈列量上限`

# 违反处置
降级处理：下单箱数改为 floor((陈列量上限 − 可用库存) / 箱规)，建议补货数量随之重算；结果为 0 时不生成该补货行，商品记入跳过商品清单。

# 来源
[[补货编制主流程]] 的步骤 3；研究报告「门店补货资料分析」关键规则第 2 条。

# 例外情况
商品未维护陈列量上限时不截断，补货行照常生成；促销期按促销陈列方案的临时上限执行，本示例不含促销。
