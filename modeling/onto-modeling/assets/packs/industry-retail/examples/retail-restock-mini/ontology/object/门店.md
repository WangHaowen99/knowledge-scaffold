# 对象描述
直接面向顾客销售的经营单元，是补货单的收货方。补货编制以门店为单位进行，停业门店不生成补货单。

# 对象别名
分店, 网点

# 英文名称
Store

# 数据来源
无
> 示例项目不附数据表；接入真实数据后改为对应的表名。

# 查询边界
按门店编码精确查询，至多 1 行；必要字段为门店编码、营业状态。无匹配门店时返回空结果，不推断门店存在。

# 对象属性清单
| 中文名称 | 英文名称 | 描述 | 主键 | 类型 | 属性别名 | 属性规则 |
|--------|--------|-----|----|-----|--------|--------|
| 门店编码 | store_code | 门店的唯一标识 | 是 | 字符串 | 店号 | 必填；唯一 |
| 门店名称 | store_name | 门店的显示名称 | 否 | 字符串 | 店名 | 无 |
| 门店等级 | store_grade | 按销售规模划分的等级 | 否 | 枚举 | 店级 | 取值：A / B / C |
| 区域编码 | region_code | 门店所属的区域 | 否 | 字符串 | 片区编码 | 必填 |
| 营业状态 | business_status | 门店当前是否营业 | 否 | 枚举 | 无 | 取值：营业 / 停业 / 筹备 |

# 关联对象
- [[补货单]] → 发往（store_code → store_code） → 当前对象
- [[库存]] → 存放于（store_code → store_code） → 当前对象
