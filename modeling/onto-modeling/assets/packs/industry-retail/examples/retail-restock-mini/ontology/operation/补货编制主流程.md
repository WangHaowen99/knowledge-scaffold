# 业务描述
为指定门店在指定补货日期编制补货单：逐个在库商品测算安全库存，判断是否需要补货，按 [[R-07 陈列上限]] 截断、按箱规取整后生成补货单明细。

# 与operation的关联
- 被operation调用 > 无
- 调用operation > [[安全库存测算]]

# 与object的关联
- 输入数据的对象：[[门店]]、[[库存]]、[[商品]]
- 输出数据的对象：[[补货单]]
- 支撑数据的对象：无

# 与object的语义关联
| 业务对象 | 语义关联关系 |
|---------|--------|
| 门店 | 确定收货方和营业状态 |
| 库存 | 提供现有库存和在途数量 |
| 商品 | 提供商品状态、箱规和陈列量上限 |
| 补货单 | 主流程的产出 |

# 触发条件
每日补货编制时点到达，或用户手动发起某门店的补货编制。

# 输入
| 参数名称 | 描述 | 输入源 |
|--------|------|-------|
| 门店编码 | 待编制补货单的门店 | 用户或定时任务传入 |
| 补货日期 | 补货单日期，同时作为库存快照日期 | 用户或定时任务传入，默认当天 |
| 订货周期天数 | 相邻两次下单的间隔天数 | 用户传入，默认 1 |
| 缓冲天数 | 安全库存测算用的缓冲天数 | 用户传入，默认 2 |
| 商品编码 | 可选；填写时只编制该商品，用于单独查询某商品的安全库存或补货量 | 用户传入，不填时遍历门店全部在库商品 |

**查询边界**：按门店编码查询 [[门店]]，至多 1 行；按门店编码、库存日期 == 补货日期 查询 [[库存]]，必要字段为商品编码、现有库存数量、在途数量，单店单日最多 5000 行，超出时按品类分批执行并在结果中注明；按商品编码查询 [[商品]]，每个商品至多 1 行。库存无匹配时返回空补货单明细并说明原因。

# 输出
| 参数名称 | 描述 |
|--------|----|
| 补货单明细 | 写入 [[补货单]] 的明细行集合 |
| 跳过商品清单 | 未生成补货行的商品及原因 |
| 安全库存 | 本次测算成功的各商品安全库存，含无需补货的商品 |

# 逻辑描述
1. 基于门店编码，读取 [[门店]].营业状态
   - if 营业状态 != "营业" then 返回空补货单明细，跳过原因 = "门店非营业"，结束
2. 基于门店编码、补货日期，查询 [[库存]]，得到库存记录集合。
   - if exists 商品编码 then 库存记录集合只保留商品编码相同的记录
3. loop 遍历 库存记录集合，当前项记为当前库存记录：
   - 基于当前库存记录.商品编码，读取 [[商品]].商品状态、箱规、陈列量上限
   - if 商品状态 != "正常" || not exists 箱规 then 记入跳过商品清单，处理下一项
   - 调用[[安全库存测算]]逻辑文档，传入门店编码、当前库存记录.商品编码、补货日期、缓冲天数，获取日均销量、安全库存、测算状态。
   - if 测算状态 != "正常" then 记入跳过商品清单（原因 = 测算状态），处理下一项
   - 将当前库存记录.商品编码与安全库存记入输出「安全库存」
   - 可用库存 = max(当前库存记录.现有库存数量, 0) + 当前库存记录.在途数量
   - if 可用库存 >= 安全库存 then 处理下一项
   - 目标库存 = 安全库存 + 日均销量 × 订货周期天数
   - 下单箱数 = ceil((目标库存 − 可用库存) / 箱规)
   - if exists 陈列量上限 && 可用库存 + 下单箱数 × 箱规 > 陈列量上限 then 下单箱数 = floor((陈列量上限 − 可用库存) / 箱规)，依据 [[R-07 陈列上限]]
   - if 下单箱数 <= 0 then 记入跳过商品清单（原因 = "已达陈列量上限"），处理下一项
   - 建议补货数量 = 下单箱数 × 箱规
   - 写入 [[补货单]]：补货单号（按门店编码与补货日期生成）、门店编码、商品编码、补货日期、建议补货数量、下单箱数、单据状态 = "草稿"。
   end loop
4. 返回补货单明细、跳过商品清单、安全库存。

```
# 示例
# 输入：安全库存 = 40，日均销量 = 10，订货周期天数 = 1，现有库存数量 = 15，在途数量 = 0，箱规 = 12，陈列量上限 = 48
# 过程：可用库存 = 15；目标库存 = 50；下单箱数 = ceil(35 / 12) = 3；15 + 36 > 48，下单箱数 = floor(33 / 12) = 2
# 输出：下单箱数 = 2，建议补货数量 = 24
```
