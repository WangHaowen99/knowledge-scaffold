# 按切片建模（建模命令共用）

对象提取、操作提取、规则抽取在 Step 0 之后先看这一份。依据：建模蓝图 `research/blueprint.json`（资料分析的切片规划）。

## 取这一次的切片

```bash
python3 .claude/scripts/blueprint.py brief
```

- 输出「全量模式：……」：没有切片规划或只有一片，照命令原来的步骤处理全部资料，下面的规则都不用看。
- 输出「切片：<片名>（<编号>）……」：这一次只做这一片。平台已按 `$ARGUMENTS` 里的 `slice=<编号>`（没带时取这一步还没做完的
  第一片）定好了是哪一片；`brief` 列出这一片的核心链路、依赖、规划的对象 / 操作 / 规则、依据的资料位置、范围外和统一叫法。
- 输出「切片 … 不存在或已排除」：告诉用户这一片不在蓝图里，停下。

## 只做这一片

- 只读这一片依据的资料位置（`brief` 的「依据」）和已有的条目；派子代理时把 `brief` 的输出原样放进 prompt。
- 只新建、修改这一片的条目：`brief` 里规划的，加上做的过程中发现、确实属于这一片的新条目（平台会把新建的记进这一片）。
- 别的片已有的条目只读（守卫会拦）：要用就链接（如 `[[商品品类]]`），不要改它；确实需要改时在回复里列出来，由用户决定。
- 范围外的内容不建；术语按「统一叫法」写。
- 规划的名字就是条目的文件名，照着用；资料里叫法不同时用统一叫法，不要另起名字。
- 规则一步：这一片没规划规则、资料里也没有时，告诉用户这一片没有规则、这一步跳过，不要硬凑。

## 收尾

这一片这一步做完就停：一两句说明这一片新增、修改了哪些条目，等用户确认生效（界面上有「这一轮改了什么」卡），
不要接着做下一片或下一步。下一步建议按 `python3 .claude/scripts/state_helper.py suggest` 的结果给，最多 3 条。
