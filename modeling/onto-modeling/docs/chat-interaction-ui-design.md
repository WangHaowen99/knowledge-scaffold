# 对话区交互 UI 设计（人因学规格）

状态:设计稿,待评审落地。范围:onto-web 右栏对话区的 11 项交互增强。
原则来源:Nielsen 十项启发式、Fitts/Hick 定律、方案文档 6.2/6.3.5。

## 0. 总体设计原则

| 原则 | 在本设计中的落法 |
|---|---|
| 状态可见性 | 会话状态/成本/上下文水位常显于右栏头部,不藏进菜单 |
| 识别优于回忆 | 路径变实体芯片(带类型图标),建议 chips 带"为什么推荐"tooltip |
| 希克定律 | 动态建议最多 4 个(1 主推 + 3 次级),全量命令收进"更多"入口 |
| 费茨定律 | 高频目标(主推建议、新消息按钮)加大且贴近拇指/光标热区 |
| 用户控制与自由 | 滚动不抢控制权、打断有续接出口、破坏性操作二次确认 |
| 防错 | 运行中隐藏建议 chips(防并发误触)、失效路径芯片降饱和 |
| 一致性 | 只用既有 CSS token;圆角:芯片 999/卡 10/按钮 8;动效统一时长 |
| 可及性 | 全部动效尊重 prefers-reduced-motion;操作均可键盘触达 |

动效阶梯:微交互 150ms / 内容出场 180ms(soft-in) / 强调入场 260ms(弱化版 bubble-pop)。
字号阶梯:正文 13 / 辅助 12 / 微标 11。

## 1. 动态"下一步建议" chips

**数据源**:阶段进度(stageProgress)+ 最近 result + 最新报告解析结果 + meta.resource_updated_at。

**规则表**(按优先级取首个主推,再补次级,总数 ≤4):

| 情境(按优先级) | 主推 chip | 次级 chips |
|---|---|---|
| 最新校验报告有错误项 | 修复报告错误项(N 个) | 打开报告评审 · 重新校验 |
| 资料更新晚于最近版本 | 让助手刷新受影响产物 | 开始资料分析 |
| 阶段 k 完成且 k+1 未开始 | 阶段 k+1 的首个动作 | 阶段 k+1 其余入口 |
| 主链全部完成 | 整体视图 | 生成脚本候选 · 导出知识包 |
| 空项目 | 开始建模 | 注入示例 · 上传资料 |

**交互**:
- 主推 chip:主色描边 + primary-soft 底 + 右箭头图标;2s 周期的轻呼吸(透明度 0.88↔1),
  reduced-motion 时静止。次级 chips 维持现有 quick-chip 样式。
- 每个 chip 带 tooltip 说明推荐理由("检测到校验报告 3 个错误项")。
- 会话运行中/排队中:整行淡出隐藏(防误触发并发消息);result 后 300ms 淡入新一组。
- 行尾固定「⋯ 更多」入口,弹出全量命令菜单(现有 6 命令 + 反查/知识库)。

## 2. 产物路径实体芯片(消息内)

**识别**:助手文本块中匹配
`(research|reports|ontology|knowledge|resource)/[^\s`）)，。;；]+\.(md|mmd|drawio|xlsx|xlsm|html|py|csv)`;
代码块/行内代码内不转换(防误伤示例代码)。

**渲染**:行内芯片 = 类型图标 + 文件名(目录中段省略,`reports/…/校验.md`),
surface-subtle 底、border-subtle 描边、圆角 999、padding 1×8、字号 12;
与 `[[wikilink]]`(主色文字链)视觉区分——芯片是"可打开的实体",链是"概念跳转"。
类型图标:md=文档、mmd/drawio=流程、xlsx=表格、html=报告、py=脚本。

**交互**:hover 抬升 1px + tooltip 完整路径;点击 → 中栏 file focus;
文件已不存在 → 芯片降饱和(alpha .55),点击 toast"文件不存在(可能已改名)"。

## 3. 每轮产物变更卡

**数据**:后端在 result 事件后 `git diff --name-status` 对比该轮起点提交,
广播 `workspace_changes {added[], modified[], deleted[], from, to}`;无变更不发。

**渲染**:轮次尾部一张非气泡低调卡:左缘 2px 主色竖条 + surface-subtle 底、圆角 10;
标题行"本轮产物变更 · 新增 a / 修改 m"+「查看对比」文字钮(→ 中栏 diff,rev=from);
正文为 §2 路径芯片流式排列;>6 个默认显 3 个 +「展开全部(N)」。
新增芯片前缀绿点、修改橙点、删除灰点+删除线(不可点击)。

## 4. 滚动锚定(修复强制滚底)

- "贴底"判定:距底 < 80px。贴底时新事件平滑滚底(流式走既有 rAF 批处理);
  不贴底时**完全不动**,右下浮出胶囊按钮「↓ 新消息 N」
  (Sender 上方 12px 居右,主色底白字、shadow-sm、260ms 弱化 pop 入场)。
- 点击按钮/手动滚回底部 → 计数清零、按钮淡出。
- reduced-motion:滚动 instant、按钮无动画。

## 5. 粘贴截图上传

- Sender 区监听 paste:剪贴板含图片 → 生成附件 chip,自动命名
  `screenshot-YYYYMMDD-HHmmss.png`,chip 内显示 40×40 圆角缩略图(替代类型图标);
  多图逐个生成;非图片剪贴板不拦截默认行为。
- 上传目录 resource/others;>20MB 拒绝并提示。
- 动效:chip 以 150ms 微 pop 进入附件行,与现有拖拽上传一致。

## 6. 右栏会话状态头部(设计 6.3.5 要求)

36px 高,border-bottom subtle。左→右:

1. **状态点+文字**:空闲=tertiary 灰 / 生成中=主色+呼吸 / 执行工具=主色实心 /
   排队=warning / 错误=error。文案:空闲·生成中·执行工具·排队第 N 位·出错了。
2. 弹性留白。
3. **累计成本**($x.xx,点击弹出用量 Popover:调用次数/输入/输出/缓存命中率/最近一轮)。
4. **上下文水位环**(稳定引擎):16px 细环,已用量取最近一次主代理调用的 usage(输入含缓存读写 + 输出;
   result 的 usage 是整轮累加,不能用),窗口与自动压缩点由引擎每轮结束下发;环 = 已用/窗口,
   用到压缩点的 75% 橙、90% 红;tooltip 给出已用/窗口/剩余与距自动压缩的余量。压缩时对话插入系统行
   "上下文已自动压缩"。
5. **重启会话** icon 钮(Popconfirm:"历史保留,模型上下文经 resume 续接")。

右栏收起时:收起条上保留状态点(状态可见性不因收起丢失)。

## 7. 工具执行详情(行内展开)

- 后端:`tool_results` 事件每块补 `excerpt`(结果文本前 400 字符,走既有脱敏管道)。
- 前端:工具行整行可点 → **行内**展开(不是抽屉,就近原则):
  输入参数格式化 JSON(key 用 tertiary 色)+ 结果摘录(等宽 12px,最多 8 行,
  超出显示"…已截断");同一工具组内手风琴(同时只展开一行);再点收起。
- 展开态背景 surface-subtle、圆角 8、180ms soft-in。

## 8. 轮次分隔与时间戳

- 每条用户消息前插入分隔线:1px border-subtle 横线,中嵌相对时间
  ("3 分钟前";>24h 显"昨天 14:32";hover 显绝对时间),文字底色 surface-page 遮线。
- 任意气泡 hover:右上角浮出 11px tertiary 时间戳(150ms 淡入)。

## 9. 助手消息操作条

hover 气泡下缘浮出胶囊组(150ms 淡入,替代现单个"沉淀知识"钮):
**复制** | **引用** | **沉淀知识**。

- 复制:按钮自身切换为"✓ 已复制"1.6s(同代码卡交互),不弹 toast。
- 引用:输入框插入 `> 原文前 120 字…\n\n`,光标定位末尾并聚焦。
- 沉淀知识:现有确认卡流程不变。
- 桌面优先;触屏长按方案后置。

## 10. ↑ 键召回历史输入

- 仅当输入框为空且会话非运行中:↑ 填入上一条用户消息,连续 ↑/↓ 前后翻,
  Esc 清空退出;召回态输入框左侧显示 11px"编辑重发"微标。
- 输入框非空时 ↑ 保持默认光标行为(不抢键)。

## 11. 打断续接

- 后端 interrupt 成功后广播 `session_interrupted`(入历史)。
- 前端渲染居中灰字系统行"— 已打断 —";同时建议区亮两个 chip:
  「继续刚才的任务」(发送"继续")、「换个方向」(仅聚焦输入框)。
