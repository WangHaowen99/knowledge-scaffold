同一套设计的分层视图：使用方 → 接入层 → 内核层 → 插件层 → 外部系统，治理平面竖贯中间三层。
层与层之间的虚线带列出层间接口，各层底部那一行是层内接口；44 个接口编号与《插件化架构全景图》一一对应。

怎么读
横向色带是层；层与层之间的虚线带是层间接口（25 个），每层底部一行是层内接口（19 个）。编号与全景图相同，悬停能看到两端模块和完整说明。
为什么两类插件都画在内核下面
能力包和可替换实现都插在内核上，区别只在契约：能力包走插件契约（manifest + 装配目录 + 扩展项），可替换实现走南向 SPI。这样摆，每个接口最多跨一层，没有跳层。
