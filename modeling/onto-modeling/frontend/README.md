# 建模工作台前端

开发：`npm run dev`；单并发测试：`node --test --test-concurrency=1`；生产构建：`npm run build`。

## 3D 图谱操作

- 工具栏搜索按名称、Key 和说明筛选图谱，保留命中节点的关联上下文；表模式保留独立的列表搜索。
- 单击节点在右侧看详情和关联，点击关联条目继续探索；双击节点进入编辑。选中后「展示方式」面板里的「再扩一跳」扩大高亮范围，「收起扩展」恢复。
- 拖动空白旋转、右键拖动平移、滚轮缩放。「展示方式」面板提供布局切换、标签与辉光、全部展开、环绕及正视、俯视、侧视和适配视图，布局切换有平滑过渡。
- 选中节点使用光环，关联边加粗；左上角图例支持显示/隐藏类型及悬停预览。节点下方只显示类型图标，名称标签按当前高亮范围展示，读屏名称包含元素类型。
- 小地图可点击导航、悬停查看名称和切换两倍大小。首次显示操作引导，关闭后在当前浏览器记忆。
- 系统开启“减少动态效果”时，环绕默认关闭，仍可点击“环绕”临时启停；相机/布局缓动、惯性和光环脉冲继续停用，导航立即完成。系统切换到“减少动态效果”会停止当前环绕；静止图谱按需绘制。

图谱展示改动不改变知识元素、关系、编辑接口或粒子功能的当前配置。
