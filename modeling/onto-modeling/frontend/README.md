# 建模工作台前端

开发：`npm run dev`；单并发测试：`node --test --test-concurrency=1`；生产构建：`npm run build`。

## 3D 图谱操作

- 图模式使用图内搜索，支持名称、Key 和说明，最多显示 8 个候选。方向键选择，Enter 定位，Esc 关闭候选；点击候选同样有效。搜索保留关联上下文，自动恢复目标类型并展开目标所在关系簇，重复提交可以重新定位。表模式保留独立的列表搜索。
- 单击节点查看摘要与关联节点，点击邻居继续探索；“定位”回到当前节点，“再扩一跳”扩大高亮范围。双击节点进入原有编辑界面。
- 拖动空白旋转、右键拖动平移、滚轮缩放。展示菜单提供正视、俯视、侧视及适配视图，两种布局切换有平滑过渡。
- 选中节点使用光环，关联边加粗；图例支持显示/隐藏类型及悬停预览。名称标签按当前高亮范围展示，读屏名称包含元素类型。
- 小地图可点击导航、悬停查看名称和切换两倍大小。首次显示操作引导，关闭后在当前浏览器记忆。
- 系统开启“减少动态效果”时，环绕默认关闭，仍可点击“环绕”临时启停；相机/布局缓动、惯性和光环脉冲继续停用，导航立即完成。系统切换到“减少动态效果”会停止当前环绕；静止图谱按需绘制。

图谱展示改动不改变知识元素、关系、编辑接口或粒子功能的当前配置。
