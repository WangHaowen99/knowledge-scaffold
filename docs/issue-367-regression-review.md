审视日期：2026-10-22。下述历史分析及初次方案对应当时的截图要求，代码行号对应 `bf36850e` 基点。2026-10-26 的最新规则为：评测允许自关联；源对象、关系名、目标对象、源关联字段、目标关联字段全部相同才判重复。最新规则覆盖本文初次方案中的自关联拒绝策略，见文末补充。

## 结论

**问题存在，但原因不是 !465 关闭了结构校验，而是实际导出、导入链路会遗漏关系，导致结构校验没有输入。**

- !465 的实现仅放宽关系名称规则；关系存在于 `PackageSpec.objects[].relations` 时，当时的代码仍会拒绝自关联和不存在的目标。
- !465 合入时，Onto Modeling 的非图模式导出只保留 `# 关联对象`，Modeling 导入端却只解析 `# 关系` 表。自关联、缺失目标乃至正常关系都会从结构化规格中消失，两种错误输入因此通过后续规格校验。原 PR 没有覆盖该集成路径。
- 最新 `develop` 又在 !486 中改变策略：图模式的关系问题只跳过单条关系，并允许规格中的自关联。这与截图要求的“启动评测前拦截”冲突。
- 截图描述的是 2026-10-19 的结果；!486 的变化发生在 2026-10-21，不能把它作为 10 月 19 日失败的起因。原始导出、导入缺口在 !465 时已存在。

## 建议修复方案

### A. 在评测入口检查原始关系，统一覆盖数据源模式

在现有关系解析模块中提取可复用的“声明解析、端点归一化、结构校验”步骤，复用 `parse_relation_definitions`，与依赖物理表绑定的图导入步骤分开。

- 同时接收工作区 `# 关联对象` 箭头格式和已导入包的标准 `# 关系` 表格式，转换为同一关系结构。
- 基于包内全部对象检查源、目标是否存在，并按本次评测策略拒绝自关联；校验不依赖对象是否绑定数据表，也不因 `allow_unbound` 跳过。
- 在 `projects.py` 的 `eval_run` 创建后台任务前运行，错误返回 HTTP 422、`EVALUATION_PACKAGE_INVALID` 和具体原因；保留对象、相对文件位置及行号，便于定位。
- 在 `_run_sync` 中、复用旧轮次或导出之前再次检查即将评测的输入，覆盖非 HTTP 调用和后台期间的修改；发现输入变化时使用当前明确的快照或要求重试，避免检查一份内容、评测另一份。
- 图片中的两类错误必须在包导入、数据导入和轮次创建之前拒绝。

### B. 所有模式导出时保留规范化关系

`export_package_zip` 在所有数据源模式下都应输出标准 `# 关系` 表。非图模式只需要语义上的源、关系名和目标，不要求建立图数据所需的物理关联字段。

图模式继续在同一份关系结构上补充关联字段和图导入信息。评测前的结构错误不得被转换为 skipped 后丢失。针对未绑定物理表等其他情况保留现有处理边界，不把全部提示升级为错误。

增加导出、导入前后的关系保留断言：正常关系必须能恢复为 `PackageSpec.objects[].relations`，并保留方向、关系名和目标。存在两种声明格式时按规范化三元组去重；冲突给出明确诊断。

### C. 保持 Modeling 评测引擎的最终防线

继续使用 `validateRelationNames: false`，保留 !465 解决的关系名称兼容性。

针对当前已允许自关联的行为，建议新增可选评测策略参数，例如 `allowSelfRelations`，默认延续当前通用行为，仅在 `startEvaluation` 显式设为 `false`。这样评测符合本次验收，而编辑、发布等调用方不会无意中改变行为。缺失目标继续强制检查。

若后续产品验收决定允许具有关联字段的合法自关联，应另行修订该项验收及测试；按当前截图，本方案将所有自关联视为评测阻断项。

## 实施记录

已在同一 worktree 和分支完成修复：

- `eval_run` 在创建后台任务前检查包内关系；自关联、缺失端点等结构问题返回 HTTP 422、`EVALUATION_PACKAGE_INVALID`、相对文件名及行号。检查覆盖所有数据源模式，`allow_unbound` 无法绕过。

## 2026-10-26 关系身份规则调整

- 评测入口和 Modeling 评测引擎允许自关联，目标不存在继续拒绝。
- 重复身份由规范化后的源对象、关系名、目标对象及两端关联字段组成。字段对不同的同名关系保留并允许评测；字段对相同的重复声明报告两处源文件及行号后拒绝启动。
- 箭头括注与标准关系表共用字段解析；`对象名.字段` 或表名前缀会还原到属性字段。未声明字段使用空字段对，不从其他同名声明补猜。
- 标准包导出、图模式导出、TypeScript 规格校验、图映射校验及关系选择界面使用同样的身份范围，防止通过入口后丢关系或再次被误拦。
- 旧验收包中将单条自关联视为反例的预期作废。新的全合成用例分别验证相同字段对重复、不同字段对同名、自关联和缺失目标。
