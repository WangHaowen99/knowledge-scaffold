## 修复内容

1. **确定性执行无法使用已验证的暂存知识包。** 运行时将版本预检所得副本绑定到内部授权上下文，确定性解析器与处理脚本分别创建附属沙箱。授权核对工作区、知识包、运行和精确路径；处理脚本仅额外获得本次调用的产物目录，以及需要时只读访问其代理目录。执行边界再次检查挂载范围，沙箱释放失败时禁止返回成功结果。
2. **6 项工具注册回归测试与现有参数证据契约不一致。** 成功场景补充明确的合成用户证据；拒绝场景经过真实脚本绑定及参数校验，仅替换最终脚本执行，检查结构化错误分类、未执行脚本，以及修正参数后可以成功重试。
3. **测试依赖和配置不完整。** 新增 `consumer/backend/requirements-test.txt`，复用后端、认证和 OR-Tools 服务已有依赖，并声明子测试插件。MCP 测试配置由夹具生成合成值；修正 4 处超长测试代码，更新干净检出与独立虚拟环境的测试说明。
4. **启动迁移后可能读取旧配置快照。** 启动过程中较早的迁移可能预热配置缓存，较晚的迁移更新文件后没有立即刷新缓存。现在成功迁移后统一刷新配置快照和环境。回归测试先缓存旧值并延长轮询间隔，修复前稳定失败，修复后通过。
